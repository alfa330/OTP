# Запрос в TEZ APP: дата регистрации водителя

Статус: **отправить в TEZ APP** (03.11.2026). Нужен для «Воронки ОП» отдела продаж Тез КЦ
(задача #407): шаги «Уже зарегистрированы» и «Зарегистрировались после контакта» и конверсия
«из диалога в регистрацию». Пока поля нет, эти шаги в воронке помечены «ждём данные TEZ APP».

## Что просим

В ответ того же эндпоинта, которым мы уже пользуемся, добавить одно поле:

```
POST https://api.tezapp.org/drivers/first-orders
{"month": "2026-11", "drivers": [{"full_name": "...", "phone": "+77012345678"}]}
```

```json
{
  "drivers": [
    {
      "full_name": "...",
      "phone": "+77012345678",
      "month_first_order_at": "2026-11-08T09:52:05+05:00",
      "last_order_before_at": "2026-06-19T10:20:27+05:00",
      "registered_at": "2026-11-05T14:03:11+05:00"
    }
  ]
}
```

| поле | смысл |
|---|---|
| `registered_at` | дата и время регистрации водителя в TEZ APP, в том же формате, что даты заказов; `null` — аккаунта нет |

Сейчас `month_first_order_at = null` не отличает «аккаунта нет» от «аккаунт есть, но не ездил»,
поэтому из дат заказов регистрацию не вывести.

## Что уточнить

1. Что считается регистрацией: создание аккаунта или его подтверждение/активация? Нам нужна
   та дата, после которой водитель может принимать заказы.
2. Если водитель регистрировался повторно (удалял аккаунт), какая дата придёт — первая или последняя?

## Просьба

Как и в августе: о смене или удалении полей предупреждать заранее. Пропажа поля не даёт ни
ошибки, ни пустого ответа — она тихо меняет цифры в отчётах.
